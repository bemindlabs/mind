Installed

Terminal should now be showing mind setup. If it is not, open Terminal and type it.

For a fully local agent, install Ollama and pull a model first; setup lists the models it finds.

To remove: sudo rm /usr/local/bin/mind && sudo pkgutil --forget com.bemindlabs.mind. Your agents and their data are not touched by removing the program — mind erase is how a subject's data goes.
