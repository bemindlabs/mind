Mind

A command-line tool that builds AI agents you own: each one has its own identity, lives in its own git repository, and runs on a local model or on the AI CLIs you already use.

This installs one file, /usr/local/bin/mind. No background service, no data, no network access during installation.

When it finishes, Terminal opens with mind setup, which walks you through a first agent one question at a time. You can close it and run mind setup later.
