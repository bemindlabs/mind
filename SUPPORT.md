# Getting help

- **Something does not work** — run `mind doctor` first: it checks each backend, the local model, the stores
  and the paths, and says what to fix. The [quickstart](docs/quickstart.md) ends with a troubleshooting table for the
  first hour. If that does not explain it, [open a bug report](https://github.com/bemindlabs/mind/issues/new/choose).
- **How do I …** — `mind help` lists every command with its flags; the [README](README.md) walks through
  installing and setting up an agent, and says [what to know before you rely on it](README.md#what-to-know-before-you-rely-on-it);
  `docs/` holds the quickstart, the architecture decisions and the demo.
- **Coming from 0.10.x** — v0.11.0 starts fresh and does not read data written by 0.10.x.
- **A security problem** — privately, as [SECURITY.md](SECURITY.md) describes. Never in an issue.

Mind is an alpha, a 0.x maintained by a small team: answers come when they can, and the newest release is the one
that gets fixes.
